# Executive Engineering

Build a premium, highly art-directed frontend website for a university student club called:

DEVOPS CLUB

Concept:
DEVOPS × SUITS

This is a Round 2 frontend design challenge and I want the result to feel like a genuine, professionally designed digital experience — NOT a typical AI-generated / vibe-coded / template website.

The website should feel inspired by the visual world of the TV series SUITS:
Manhattan corporate law firms, tailored suits, boardrooms, New York skyline, negotiation, strategy, confidence, precision, power, secrecy, case files and high-stakes decisions.

IMPORTANT:
This is INSPIRED BY the visual language of Suits.
Do not simply copy the show's website, posters, exact layouts, copyrighted promotional artwork, or official branding.
Create an original DEVOPS CLUB identity using the Suits-inspired visual direction.

## TYPOGRAPHY

Typography is extremely important.

The typography should feel like:
premium corporate editorial design + Suits-style title treatment.

Use only TWO font families.

DISPLAY / HEADINGS:
Use a DIN-style condensed grotesk.

Preferred direction:
Barlow Condensed or another close, high-quality condensed sans-serif.

Use it for:

* hero title
* section titles
* major statements
* large numbers

BODY / UI:
Use Manrope or another clean modern professional sans-serif.

Use it for:

* paragraphs
* navigation
* descriptions
* buttons
* team information
* metadata

Do NOT use:

* Poppins
* overly rounded fonts
* playful fonts
* futuristic sci-fi fonts
* handwriting fonts
* excessive serif usage

Typography should feel expensive and intentional.

## INTERACTION DESIGN

The site should have subtle premium micro-interactions.

Use lightweight CSS animations.

Examples:

* headings slightly shift on hover
* red accent lines expand
* image crops shift subtly
* buttons move 2–3px
* navigation indicators animate
* team images transition from monochrome to slightly more contrast
* case-file items reveal additional information

Animations should be:
fast
controlled
subtle
intentional

Do NOT use:

* cursor trails
* particles
* floating blobs
* continuous background animation
* excessive parallax
* scroll-jacking
* bouncing cards
* huge zoom effects

---

## SCROLL EXPERIENCE

Use subtle scroll-based reveals.

Sections should:

* fade in softly
* move upward slightly
* reveal text in staggered fashion

Use lightweight CSS / IntersectionObserver where useful.

Do not install heavy animation libraries.

No GSAP.
No Three.js.
No WebGL.

Prioritize smooth scrolling and good performance.

---

## RESPONSIVE DESIGN

The website must look excellent on:

* desktop
* laptop
* tablet
* mobile

Mobile must not simply be a shrunk desktop.

On mobile:

* simplify layouts
* stack editorial columns intelligently
* reduce decorative elements
* maintain typography hierarchy
* prevent horizontal overflow
* keep CTAs accessible
* preserve the premium visual identity

---

## PERFORMANCE

Performance is extremely important.

Use:

* CSS transforms
* opacity
* lightweight transitions
* optimized images
* minimal JavaScript
* lazy loading where appropriate

Avoid:

* unnecessary packages
* heavy animation libraries
* continuous mouse listeners
* expensive blur effects
* large background videos
* canvas effects
* WebGL
* excessive DOM complexity

The page must remain smooth on average student laptops and mobile devices.

---
