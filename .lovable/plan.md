# DEVOPS CLUB Editorial Website

## Direction
Build a single-page, cinematic editorial experience combining Manhattan corporate restraint with engineering precision. Use the supplied black, navy, off-white, red, and steel palette; Barlow Condensed for display type; and Manrope for body/UI.

## Build
- Replace the placeholder home page with eight connected sections: navigation, hero, club story, case-file focus areas, six-person fictional team, culture principles, final call-to-action, and footer.
- Create an original monochrome architectural hero image and six cohesive fictional editorial portraits; optimize and load imagery responsively.
- Use asymmetric grids, thin rules, oversized type, case-file indexing, precise metadata, and restrained red accents rather than generic cards.
- Add a compact mobile menu, anchor navigation, keyboard-visible focus states, semantic landmarks, meaningful alt text, and accessible controls.
- Add lightweight IntersectionObserver reveals and CSS-only hover details, with reduced-motion support and no animation libraries.
- Update page metadata and font loading while keeping the project frontend-only and dependency-free.

## Validation
- Check current build diagnostics.
- Verify the full page at desktop and mobile sizes for layout, overflow, navigation, imagery, and interactions.
- Confirm metadata and accessibility basics are present.
